DeepSeek çalışma aktarımı

Kontrollü

Bir tur seç; talimatı DeepSeek Chat'e kendin aktar. Üretilen yanıtı kopyalayıp aşağıya yapıştır ve doğruladıktan sonra kaydet. Eklenti DeepSeek sitesindeki sohbeti okumaz.

Henüz çalışma turu seçilmedi.

GitHub

Bağlanmadı

Yalnızca seçtiğin depolara erişebilen fine-grained personal access token oluştur. Contents: Read and write izni gerekli. Depolara kaynak kod yerine sadece ayrı embasic-agent/… dalında rapor yazılır.

Token varsayılan olarak yalnızca Chrome oturumunda tutulur. Şifreli kasayı seçersen token diskte AES-256-GCM ile korunur. Unutulan kasa parolası kurtarılamaz; yeni GitHub token gerekir.

Google Drive

Bağlanmadı

Resmî Google OAuth kullanır. Google hesabının parolasını eklentiye girmezsin. Yalnızca eklentinin oluşturduğu/seçtiğin dosyalara erişmeyi amaçlayan drive.file yetkisi kullanılır.

İlk kurulumda Google Cloud üzerinde bir Chrome Extension OAuth Client açıp istemci kimliğini manifest.json içine eklemek gerekir. Kurulum kılavuzuna bak.

Aktarım dizini: Drive / EMBASIC DeepSeek Agent / [Proje Adı + Görev Kimliği] / [Tur UUID].md

Çalışma biçimi ve sınırlar

Güvenli mod

Bu sürümde DeepSeek Free sohbetinde cevap üretimini sen başlatırsın. Uzantı API veya site içi gizli uç nokta kullanarak bu süreci otomatikleştirmez.

Saatlik görevler bilgisayar uykudayken gecikebilir. Uygulama her görev için en fazla bir bekleyen talimat oluşturur, kaçırılmış saatler için toplu istek üretmez.

Yerel arşiv kasası etkinleştirildiğinde proje ve yanıtlar AES-256-GCM ile şifrelenir. Önceki sürümün açık metin verilerini kasaya taşıyabilirsin; güvenli silme işletim sistemi veya SSD üzerinde garanti edilemez. Şifreni kaybedersen kurtarma yoktur.

Yedek geri yükleme tüm görevleri duraklatır ve önceki raporların tekrar internete gönderilmesini kapatır. GitHub token yedeklere dahil edilmez.
